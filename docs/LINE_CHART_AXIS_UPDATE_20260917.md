# 论文折线图纵轴调整

本次修改改善真实性能差距的可读性，未改动实验数据、模型、样本选择或论文中的收益数字。

- P95/P99 随负载变化的四面板图：改为每种方法相对同条件 ECMP 的 FCT 比值，使用线性纵轴；所有面板范围统一为 0.4–1.9。
- All-Reduce 四面板图：改为任务完成时间 / 同条件 ECMP 任务完成时间，线性纵轴统一为 0.5–1.1。
- All-to-All 四面板图：采用相同换算，纵轴统一为 0.6–1.7；CABLE 退化的情况仍然可见。
- 单独模型拟合曲线：保留相对适配 ConWeave 的 P99 百分比变化，共用 −40% 至 +5% 的纵轴，每 5 个百分点一个刻度。

比值 1 表示与 ECMP 持平，低于 1 表示完成更快。先在同条件内相除，再对 log 比值平均并取指数；置信区间保留原协议的种子块和模型重采样。比值随消息大小下降不表示绝对耗时下降，图注与纵轴均明确标识了比值。

所有纵轴范围根据全部算法及完整 95% 区间确定，包含基准线，不按 CABLE 单独选范围。每张图内各面板共享尺度。原有未连线误差棒图、热图、计数柱图和拓扑图保持原样。

独立复核检查了 288 个归一化点、576 个区间端点、24 个单模型数值及 1008 个同条件算法排序，均通过。两个原始结果集及两个汇总文件均与修改前逐字节一致。论文仍为 12 页正文、2 页参考文献、3 页附录。
